STORED PROCEDURE: Stored Procedure, SQL Server içinde kaydedilen ve gerektiğinde C# tarafından çağrılarak çalışan hazır SQL komutlarıdır.

YAPISI:

CREATE OR ALTER PROCEDURE ProsedurAdi

    @Parametre2 VeriTipi

AS
BEGIN

    SQL KOMUTLARI

END
GO

Buradaki bölümler:

CREATE OR ALTER PROCEDURE

Prosedürü oluşturur. Daha önce varsa günceller.

@Parametre

C# tarafından gönderilecek değerleri alır.

AS
BEGIN

Prosedürün çalıştıracağı kodların başladığı yerdir.

END

Prosedürün bittiği yerdir.

ÖR:

CREATE OR ALTER PROCEDURE SP_Kullanicilar_Ekle

    @KullaniciAdi NVARCHAR(50),
    @Sifre NVARCHAR(50),
    @Ad NVARCHAR(50),
    @Soyad NVARCHAR(50),
    @Telefon NVARCHAR(13),
    @Mail NVARCHAR(100),
    @RolId INT,
    @AktiflikDurumu BIT,
    @ProfilResim NVARCHAR(200)

AS
BEGIN

    INSERT INTO Kullanicilar
    (
        kullanici_adi,
        sifre,
        ad,
        soyad,
        telefon,
        mail,
        rol_id,
        aktiflik_durumu,
        olusturulma_tarihi,
        profil_resim
    )
    VALUES
    (
        @KullaniciAdi,
        @Sifre,
        @Ad,
        @Soyad,
        @Telefon,
        @Mail,
        @RolId,
        @AktiflikDurumu,
        GETDATE(),
        @ProfilResim
    );

END
GO

Kullanicilar.cs sınıfındaki Ekle() metodu prosedürü çağırır:

public void Ekle()
{
    using (SqlConnection sqlConnection = Baglanti())
    {
        SqlCommand sqlCommand =
            new SqlCommand(
                "SP_Kullanicilar_Ekle",
                sqlConnection
            );

        sqlCommand.CommandType =
            CommandType.StoredProcedure;

        sqlCommand.Parameters.AddWithValue(
            "@KullaniciAdi",
            KullaniciAdi
        );

        sqlCommand.Parameters.AddWithValue(
            "@Sifre",
            Sifre
        );

        sqlCommand.Parameters.AddWithValue(
            "@Ad",
            Ad
        );

        sqlCommand.Parameters.AddWithValue(
            "@Soyad",
            Soyad
        );

        sqlCommand.Parameters.AddWithValue(
            "@Telefon",
            Telefon
        );

        sqlCommand.Parameters.AddWithValue(
            "@Mail",
            Mail
        );

        sqlCommand.Parameters.AddWithValue(
            "@RolId",
            RolId
        );

        sqlCommand.Parameters.AddWithValue(
            "@AktiflikDurumu",
            AktiflikDurumu
        );

        sqlCommand.Parameters.AddWithValue(
            "@ProfilResim",
            ProfilResim
        );

        sqlCommand.ExecuteNonQuery();
    }
}

DETAYLAR:

- sqlCommand.CommandType = CommandType.StoredProcedure;

Bu satır, yazdığımız ifadenin normal SQL sorgusu değil, Stored Procedure adı olduğunu belirtir.

- sqlCommand.Parameters.AddWithValue("@Mail", Mail);

C# içindeki Mail değerini prosedürdeki:

@Mail

parametresine gönderir.

Parametre isimleri birebir uyumlu olmalıdır.

DOSYA İŞLEMLERİ CLASS'I:

using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
using System.IO;

namespace ModbusProjesi.AppCode
{
    public class DosyaIslemleri
    {
        public string ResimKaydet(HttpPostedFile dosya)
        {
            string uzanti = Path.GetExtension(dosya.FileName).ToLower();

            string yeniDosyaAdi = System.Guid.NewGuid().ToString() + uzanti;

            string yol = HttpContext.Current.Server.MapPath("~/Files/") + yeniDosyaAdi;

            dosya.SaveAs(yol);

            return yeniDosyaAdi;
        }

        public void ResimSil(string dosyaAdi)
        {
            if (string.IsNullOrEmpty(dosyaAdi))
                return;

            string yol = HttpContext.Current.Server.MapPath("~/Files/") + dosyaAdi;

            if (File.Exists(yol))
            {
                File.Delete(yol);
            }
        }
    }
}

1) ResimKaydet()
public string ResimKaydet(HttpPostedFile dosya)
Ne yapar?

Kullanıcının yüklediği resmi sunucuya kaydeder ve dosyanın yeni adını geriye döndürür.

Parametre:

HttpPostedFile dosya

Bu, FileUpload kontrolünden gelen dosyadır.

Örneğin:

FileUpload1.PostedFile
Dosya uzantısını alma
string uzanti = Path.GetExtension(dosya.FileName).ToLower();

Örnek:

Kullanıcı yükledi:

resim.jpg

Sonuç:

.jpg

Amaç:

Dosyanın türünü öğrenmek.

Benzersiz dosya adı oluşturma
string yeniDosyaAdi = Guid.NewGuid().ToString() + uzanti;

Örneğin:

Eski isim:

profil.jpg

Yeni isim:

7f3a54c6-5fd0-43dd-9f5b-34ad7f31c5c8.jpg
Neden GUID kullandık?

Çünkü iki kullanıcı aynı isimde dosya yükleyebilir.

Örneğin:

profil.jpg

başka kullanıcı da yükleyebilir.

GUID sayesinde isimler çakışmaz.

Dosyanın kaydedileceği yolu oluşturma
string yol = HttpContext.Current.Server.MapPath("~/Files/") + yeniDosyaAdi;

Burada:

~/Files/

uygulamadaki Files klasörüdür.

Örneğin:

C:\Projeler\AsyModbus\Files\

olabilir.

Sonuç:

C:\Projeler\AsyModbus\Files\
7f3a54c6.jpg
Dosyayı kaydetme
dosya.SaveAs(yol);

Artık dosya gerçekten bilgisayara kaydedilir.

Dosya adını döndürme
return yeniDosyaAdi;

Neden tam yolu döndürmüyoruz?

Çünkü veritabanında sadece:

7f3a54c6.jpg

saklamak yeterlidir.

Daha sonra:

~/Files/

ile birleştirerek resmi gösterebiliriz.

7f3a54c6.jpg

UNIQUE: UNIQUE, bir sütundaki verilerin tekrar etmesini engelleyen SQL Server kısıtlamasıdır.

YAPISI:

Kullanıcı Kaydet
        ↓
SP_Kullanicilar_EKLE
        ↓
SQL Server
        ↓
UNIQUE kontrolü

Catch bloğu ne yapıyor?
catch(Exception ex)

Bu blok oluşan hatayı yakalar.

ÖR:

if(ex.Message.Contains("UQ_Kullanicilar_KullaniciAdi"))

kontrolü yapılır.

Yani:

"Hata kullanıcı adı UNIQUE kısıtlamasından mı geldi?"

Eğer geldiyse:

lblMesaj.Text = "Bu kullanıcı adı zaten kullanılmaktadır.";

kullanıcıya teknik hata yerine anlaşılır mesaj gösterilir.
